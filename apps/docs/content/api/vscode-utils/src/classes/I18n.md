### Constructor

> **new I18n**(`messages?`, `language?`): `I18n`

Defined in: packages/vscode-utils/src/i18n.ts:83

Loads the nls messages for the given messages or path.

#### Parameters

##### messages?

`string` \| `Record`\<`string`, `string`\>

The i18n messages or extension path.
- If a string is passed, it will be used as the extension path.
- If an object is passed, it will be used as the messages.
- If nothing is passed, you can use [use](#use) to load the messages later.

##### language?

`string`

The language to load. Defaults to env.language.

#### Returns

`I18n`

### t()

> **t**(...`params`): `string`

Defined in: packages/vscode-utils/src/i18n.ts:106

Marks a string for localization. If a localized bundle is available for the language specified by
env.language and the bundle has a localized value for this message, then that localized
value will be returned (with injected args values for any templated values).

#### Parameters

#### Example
